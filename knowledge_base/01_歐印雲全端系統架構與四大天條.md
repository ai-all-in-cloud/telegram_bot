## 🚫 開發與維運四大天條

1. **正式站與測試站嚴格隔離天條**：
   - **正式站目錄 (`C:\bakery_rebuild`)**：對外提供服務之生產環境。未經技術主管明確指示，**嚴禁執行 git pull、sync、重新打包或重啟正式服務**。
   - **測試站目錄 (`C:\bakery_rebuild_dev`)**：日常所有重構、功能研發、單元驗證之工作目錄。收工 commit / push 均在此執行。
2. **MSSQL 2003 舊資料庫直連隔離天條**：
   - 禁止在前台或客戶端直接連接資料庫，必須統一透過後端連線池與預存程序存取，防止高併發超賣與連線耗盡。
3. **無黑窗常駐守護天條**：
   - 所有後台監聽服務（如 Telegram Bot、監控程式）必須以 `wscript.exe` / VBS 或工作排程器無黑窗背景常駐運行。
4. **向下累加開發日誌天條**：
   - 每日開發工作、故障排除與架構調整，必須依日期以「向下累加 (Append)」原則記載於日誌，嚴禁覆蓋既有歷史紀錄。
