## 🕒 【全域天條】全體 AI 員工每小時雙軌輪巡與專屬工作區規範

1. **每小時雙軌輪巡 (Mandatory Hourly Polling)**：
   * 軌道一【共同知悉】：全體員工每小時主動檢閱 `代理共同知識庫\`，掌握企業全域規章。
   * 軌道二【專屬工作區】：全體員工每小時必須至個人目錄（`#員工資料\001` ~ `004` 之 `交辦事項/`）巡視是否有最新任務公文。
2. **交辦精準分流，絕不混淆**：
   * 洪正清董事長與長官之交辦事項，由總經理柚金精準投放到各受派員工之專屬 `交辦事項\` 目錄，杜絕跨區混淆。
3. **入庫即刻登載日誌**：
   * 任何新交辦一旦於個人工作區巡檢發現，100% 必須立刻登載至個人當日 `員工日誌\YYYY-MM-DD_log.md` 啟動執行！

## 🛡️ 共同知識庫協作守則

1. **人人皆可編輯**：全體代理人與團隊成員皆有權限新增、維護、補充最新技術文件。
2. **向下累加原則**：更新文件時盡量採取「向下累加 (Append)」或清楚標註版本歷程，避免不慎覆寫其他成員的重要筆記。
3. **保持純淨安全**：嚴禁存放底層機密連線金鑰與私鑰，保持知識庫安全合規。
